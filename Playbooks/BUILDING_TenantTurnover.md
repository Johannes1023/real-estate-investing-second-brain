# Tenant-turnover playbook

## Summary

A repeatable checklist links the tenancy, lease, handover, and index after a move-out.

## Trigger and goal

Trigger: notice of a tenant change for any unit. Goal: keep the private originals and topic notes synchronized.

## Steps

1. Confirm the unit ID and review its current tenant, lease, and handover notes.
2. Handle legally required notices and actual documents outside this demo; check current local rules.
3. Record a dated move-out handover with keys and meter readings in `Handovers/`.
4. Mark the superseded tenant and lease notes `outdated`, retaining their history.
5. Create a new neutral tenant-group note, a lease summary, and a move-in handover.
6. Add any real deadlines to note metadata, then run `Update`.

Use [U05 move-in](../Handovers/U05_MoveIn.md) as a completed synthetic format example.

# Private-document map

## Summary

This map shows document categories and note links without publishing a storage URL or originals.

## Document categories

| Category | Synthetic reference pattern | Linked note |
|---|---|---|
| Lease originals | `SAMPLE-<UNIT>-LEASE` | `Leases/` |
| Purchase originals | `SAMPLE-<UNIT>-PURCHASE` | `Purchases/` |
| Loan originals | `SAMPLE-<UNIT>-LOAN` | `Loans/` |
